# 手牌审计里的 χ²（卡方）与 p 值：给运营的说明

本文说明后台「牌面是否均匀」检验在算什么、数字怎么来、该怎么读。**不要求统计学背景**；若与接口字段对照，见同目录下的 `hand-poke-audit-web-api.md`。

---

## 1. 我们在回答什么问题？

- **假设**：如果发牌是公平的，那么长期来看，**52 种牌在有效底牌里出现的次数应该差不多**（每种期望占比约 1/52）。
- **做法**：把用户历史上所有**有效两手牌**拆开成一张张牌，数出每种牌出现了多少次，和「均匀分布」下应有的次数比一比。
- **输出**：
  - **χ²（chiSquare）**：整体偏差的汇总指标，**越大表示和「均匀」差得越远**。
  - **p 值（pValue）**：在「真的均匀」的前提下，**出现当前或更极端偏差**的近似概率（见下文）。
  - **状态**：样本够大且 **p < 0.05** 时标为 **abnormal（异常）**，否则在够样本时标 **normal**；样本不够则为 **insufficient_data**。

**重要**：这检验的是「分布是否像均匀随机」，**不能**直接等同于「作弊」；异常只表示**值得进一步排查**（数据问题、玩法偏置、样本巧合等都有可能）。

---

## 2. 0.05（HAND_POKE_AUDIT_ALPHA）是怎么来的？

- **不是**从牌或代码里推出来的常数，而是统计学里常用的 **显著性水平 α = 5%**。
- **含义**：若我们约定「**p 小于 5%** 就认为结果**足够罕见**，值得标红」，则 α 取 **0.05**。
- **可改吗？** 可以，但这是全行业标准习惯之一；改成 0.01 会更严（更少标异常），0.10 会更松。当前产品选择 **0.05** 写在常量 `HAND_POKE_AUDIT_ALPHA` 里。

---

## 3. χ² 和自由度是什么关系？「大于多少算异常」？

### 3.1 自由度（df）

- 我们有 **52 个格子**（52 种牌），在「总数固定」的前提下，只有 **51 个格子**可以自由变化（最后一个由总和凑齐），所以 **自由度 df = 51**。
- 代码里：`HAND_POKE_AUDIT_DF = 52 - 1`。

### 3.2 χ² 怎么算？（与代码一致）

记：

- **N** = 参与统计的牌张总数（接口里的 `cardCount`，= 有效手数 × 2）。
- 对每一种牌：**O** = 实际出现次数（`count`），**E** = 期望次数 = **N ÷ 52**（每条里的 `expectedCount` 都相同）。

则：

\[
\chi^2 = \sum\_{\text{52 种牌}} \frac{(O - E)^2}{E}
\]

直觉：**每种牌偏得越远，\((O-E)^2/E\) 越大，加起来就越大**。

### 3.3 「χ² 大于几算异常？」

- **不能**只凭 χ² 一个数、不说明自由度就下结论；**同一 χ²，df 不同，罕见程度不同**。
- 本系统**不以「χ² 超过某固定数」判异常**，而是：用 **df = 51** 算出 **p 值**，再看 **p < 0.05** 与否。
- **大致量级（帮助建立感觉，以系统显示的 p 为准）**：在 **df = 51、α = 0.05** 下，用与后台相同的近似算法，观测 χ² 大约在 **69 附近**会对应 **p ≈ 0.05**；χ² **更大**则 p **更小**、更容易标异常。

---

## 4. p 值在算什么？`chiSquareUpperTailPValue` 在干什么？

### 4.1 p 值的含义（上侧）

- 在 **「均匀发牌」为真** 的前提下，我们算出一个 χ² 统计量。
- **p 值** ≈ **P(随机均匀发牌时，χ² 会大到 ≥ 当前观测值)**，也就是**上侧概率**（越大越「不像均匀」）。
- **p 小**（如 0.03）：在均匀假设下，这么「偏」的情况比较少见 → 标 **abnormal**。
- **p 大**（如 0.40）：在均匀假设下，这种程度的波动还算常见 → 标 **normal**。

### 4.2 为什么用近似，而不是查表？

- 精确算 χ² 分布的尾概率要用较复杂的函数；工程上常用 **Wilson–Hilferty 正态近似**：把 **(χ²/df) 的立方根** 近似成正态，再换算成概率。
- **适用**：自由度不太小时较常用；本场景 **df = 51**，属于常见用法。
- **代码在做的步骤（简化理解）**：
  1. 设 **ν = df**，算 **h = 2/(9ν)**。
  2. 算 **z = ((χ²/ν)^(1/3) − (1 − h)) / √h**（把立方根标准化）。
  3. **p = 1 − Φ(z)**，其中 **Φ** 是标准正态的累积分布（代码里用 **误差函数 erf** 算正态 CDF）。
  4. 把 p **限制在 0 ～ 1** 之间，避免数值误差越界。

这与数学定义「**P(X > χ²)，X ~ χ²(df)**」一致，只是用近似公式算这个概率。

---

## 5. 和详情页「每张牌」的关系

- **总 χ²** 是 52 个格子各自贡献 \((O-E)^2/E\) 的**总和**。
- 单张牌的 **Pearson 残差** **(O−E)/√E** 的**平方**，就是这一格对总 χ² 的贡献；详情里用残差做绿/黄/红是**辅助看哪几张偏得多**，**整体是否标异常仍以总 p 值与 α=0.05 为准**。
- 样本不足（未满 150 手有效底牌）时，**不算 χ²/p**，也不启用热力标尺；避免小样本误读。

---

## 6. 运营看图时建议怎么说

| 情况              | 建议表述                                                                              |
| ----------------- | ------------------------------------------------------------------------------------- |
| insufficient_data | 有效手数不足，检验未做；可看 raw 次数，勿过度解读。                                   |
| normal            | 在当前样本量下，与「52 张牌均匀出现」的差异**未**达到我们设定的显著标准（p ≥ 0.05）。 |
| abnormal          | 与均匀假设差异在统计上较显著（p < 0.05），建议**结合业务**再查，避免直接定性。        |

**避免**：「p 值 = 作弊概率」「χ² 越高越坏」这种不准确说法。更准确的是：**在「均匀」假设下，这么极端的结果有多罕见**。

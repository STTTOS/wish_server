# Pearson 残差（pearsonResidual）：计算、含义与渐变展示

本文对应手牌审计详情里 `pokeDistribution` 每一项的 **`pearsonResidual`**，说明其**怎么算**、**代表什么**，以及前端如何用它做**绿 → 黄 → 红**等渐变展示。

---

## 1. 如何计算

记（与详情接口数据一致）：

- **N**：参与统计的牌张总数（即 `cardCount`，有效手数 × 2）。
- **O**：某一种牌的实际出现次数（该行的 `count`）。
- **E**：在「52 种牌均匀出现」假设下，**每一种牌**的期望次数：

\[
E = \frac{N}{52}
\]

**Pearson 残差**定义为：

\[
\text{pearsonResidual} = \frac{O - E}{\sqrt{E}}
\]

实现上等价于：先算 `expected = N / 52`，再 **`(count - expected) / Math.sqrt(expected)`**。

**何时为 `null`**：当 **N ≤ 0**（无有效牌张）时，不定义残差，接口中该项为 **`null`**（期望次数也会按 0 处理）；**N > 0** 时 52 项均有数值。

---

## 2. 含义是什么

### 2.1 与 χ² 的关系

对 52 种牌分别算 Pearson 残差 **r**，则：

\[
\chi^2 = \sum\_{k=1}^{52} r_k^2
\]

即**总卡方统计量 = 各格残差的平方和**。某一格的 **|r| 越大**，这一格对整体「偏离均匀」的贡献越大。

### 2.2 直观理解

- **分母 √E**：把「多出现或少出现几张」换算成**与波动量级可比**的标准化偏差，避免「期望本来就大时，多几张不算啥；期望小时多一张就很扎眼」无法横向比较的问题。
- **符号**：
  - **r > 0**：该牌出现得**比均匀假设偏多**；
  - **r < 0**：**偏少**。
- **大样本下的经验尺度（探索用，不是严格检验阈值）**：在近似正态思路下，**|r| ≈ 2** 常被视为「略偏」，**|r| ≈ 3** 常被视为「很偏」。  
  注意：52 格**不相互独立**（总和固定），**不要**把单格 |r| 当成独立事件的 p 值；单格着色是**辅助看图**，**整体是否异常仍以接口里的总 χ² / p 值与 `auditStatus` 为准**。

## 3. 如何用残差做渐变展示

### 3.1 是否启用着色

详情里另有 **`heatmapScaleEnabled`**（当有效手数 **≥ 150** 时为 `true`，与整体 χ²/p 是否可算对齐）。

| `heatmapScaleEnabled`   | 建议 UI                                                                                                       |
| ----------------------- | ------------------------------------------------------------------------------------------------------------- |
| **`false`**（样本不足） | **不要**按 `pearsonResidual` 做告警色渐变；用中性色或仅展示 `count` / `expectedCount`，避免小样本下残差误导。 |
| **`true`**              | 可按下文对 **`pearsonResidual`**（通常取 **绝对值** 或保留符号做双色）做渐变。                                |

`pearsonResidual === null` 时，该格不着热力色即可。

### 3.2 按 |r| 分段（简单稳妥）

在 **`heatmapScaleEnabled === true`** 时，用 **t = \|pearsonResidual\|** 映射颜色，例如：

| **t = \|r\|** | 建议颜色  | 含义（展示文案可弱化统计术语）     |
| ------------- | --------- | ---------------------------------- |
| **t ≤ 2**     | 浅绿      | 与期望接近常见波动范围             |
| **2 < t ≤ 3** | 黄 / 琥珀 | 偏离较明显，值得关注               |
| **t > 3**     | 红        | 偏离更明显，可结合总检验与业务排查 |

边界 2、3 可按产品微调；也可在区间内做**线性插值**（例如绿 → 黄、t 从 2 到 3；黄 → 红、t 从 3 到 4），并对 **t ≥ 某上限（如 4 ～ 5）饱和为红**，避免极端值把色条拉爆。

### 3.3 连续渐变（示例思路）

1. 令 **t = clamp(\|r\|, 0, tMax)**，`tMax` 可取 4 或 5。
2. 将 **t / tMax** 当作 0 ～ 1 的「强度」，在 **绿 → 黄 → 红** 两条线段上插值（例如 0 ～ 0.5 绿到黄，0.5 ～ 1 黄到红）。
3. 背景色或柱条填充使用该颜色；文字对比度不足时加深描边或改用左侧色条 + 右侧数字。

### 3.4 是否用符号

- **只关心「偏得多不多」**：用 **|r|** 上色即可。
- **要区分偏多 / 偏少**：可在同一色相下用**深浅**或**蓝绿 vs 橙红**区分正负，但信息密度较高，需与设计师约定。

### 3.5 与 `expectedCount` 的配合

渐变**可直接只依赖 `pearsonResidual`**。`expectedCount` 便于 tooltip 写「观测 **count** / 期望 **expectedCount**」，帮助理解颜色从哪来的。

---

## 4. 小结

| 项目     | 内容                                                 |
| -------- | ---------------------------------------------------- | --- | ------------------------------------------------------ |
| **公式** | `(count - N/52) / sqrt(N/52)`，N 为 `cardCount`      |
| **意义** | 标准化「这张牌比均匀假设多/少了多少」；**Σ r² = χ²** |
| **渐变** | **`heatmapScaleEnabled`** 为真时用 \*\*              | r   | \*\*（或带符号方案）映射绿 → 黄 → 红；为假时不着热力色 |

# χ²（卡方）与 p 值 解读

本文说明手牌审计中 **χ²** 与 **p 值**分别表示什么、怎样计算，以及如何理解检验结论。

---

## 1. 检验在回答什么问题？

- **前提想法**：若发牌在牌面分布上是公平的，长期来看，**52 种牌在统计样本里出现的次数应大致接近**（每种约占 1/52）。
- **做法**：把符合规则的**两手底牌**逐张拆开，统计每种牌出现的次数，与上述「均匀」下的期望次数对比。
- **两个输出量**：
  - **χ²**：把「每种牌偏了多少」汇总成一个数，**越大表示整体与均匀假设差得越远**。
  - **p 值**：在**假定确实均匀**的前提下，**出现当前或更极端的 χ²** 有多大的可能性（越小越「少见」，越值得注意）。

**注意**：这衡量的是「分布是否像均匀随机」，**不能**直接等同于「作弊」；显著时只说明**值得结合业务再排查**。

---

## 2. 显著性水平 0.05 是什么？

- **0.05** 不是从牌里推出来的，而是常用的 **5% 显著性水平**。
- **用法**：约定当 **p < 5%** 时，认为在「均匀」假设下当前结果已**足够罕见**，检验结论记为「与均匀差异显著」。
- 也可以选用更严（如 1%）或更松（如 10%）的标准；5% 是行业里很常见的一种默认选择。

---

## 3. χ² 怎么算？和自由度有什么关系？

### 3.1 自由度

- 共有 **52 种牌**，在**总张数固定**时，只有 **51** 个频数可以自由变化（最后一个由总和决定），因此 **自由度 df = 51**。

### 3.2 χ² 的计算式

记：

- **N** = 参与统计的牌张总数（例如有效手数 × 2）。
- 对每一种牌：**O** = 实际出现次数，**E** = 在均匀假设下的期望次数 = **N ÷ 52**（对 52 种牌，**E 相同**）。

则：

\[
\chi^2 = \sum\_{\text{52 种牌}} \frac{(O - E)^2}{E}
\]

**直观理解**：某一种牌偏得越远，\((O-E)^2/E\) 越大；对 52 种求和，得到整体的「偏离程度」。

### 3.3 χ² 大到多少算「异常」？

- **不能**只看 χ²、不说明自由度：同样大小的 χ²，**df 不同，稀有程度不同**。
- 实务上通常**先由 χ² 与 df 算出 p 值**，再用 **p 是否小于 0.05**（或你们采用的其他阈值）下结论。
- **数量级参考**（以系统给出的 p 为准）：在 **df = 51** 且采用 **5%** 标准时，观测 χ² 大约在 **69 附近**常对应 **p ≈ 0.05**；χ² **更大**则 p **更小**，更容易被判为与均匀差异显著。

---

## 4. p 值表示什么？怎样算出来？

### 4.1 含义（上侧概率）

- 在 **「均匀发牌」成立** 的假设下，根据数据算出一个 χ²。
- **p 值** ≈ **若真的均匀，随机波动下 χ² 至少达到当前这么大** 的概率（数学上记为 **P(X ≥ 观测 χ²)**，其中 **X** 服从 **df = 51** 的 χ² 分布）。
- **p 较小**（如 0.03）：在均匀假设下，这么偏的情况相对少见 → 常解释为「与均匀差异显著」。
- **p 较大**（如 0.40）：在均匀假设下，这种程度的整体偏差仍较常见 → 常解释为「未检出与均匀的显著矛盾」。

### 4.2 数值上如何得到 p？

- χ² 分布的尾概率可用精确公式或**近似公式**计算；其中一种常用近似是 **Wilson–Hilferty**：把 **(χ²/df) 的立方根** 近似成正态变量，再换算成概率。
- **步骤概要**（与定义 **P(X > χ²)，X ~ χ²(df)** 一致，仅为便于手算或理解近似思路）：
  1. 记 **ν = df**，算 **h = 2/(9ν)**。
  2. 算 **z = ((χ²/ν)^(1/3) − (1 − h)) / √h**。
  3. **p = 1 − Φ(z)**，其中 **Φ(z)** 为标准正态分布的累积概率（即 z 左侧的面积）。
  4. 将算出的 p **限制在 0 ～ 1** 之间，避免舍入误差越界。

---

## 5. 与「每张牌」展示的关系

- **总 χ²** 等于 52 种牌各自 **\((O-E)^2/E\)** 的**相加**。
- 若界面上有单张牌的偏差提示（例如由 **(O−E)/√E** 派生），那是**看哪一种牌贡献大**；**是否整体判为显著，仍以总 χ² 对应的 p 值与所选显著性水平（如 5%）为准**。
- 当**有效样本过少**时，不宜做 χ²/p 推断，系统通常**不给出**这两项或不给热力含义，以免小样本误读。

---

## 6. 如何表述更稳妥？

| 检验结果（常见展示）          | 建议理解方式                                                                       |
| ----------------------------- | ---------------------------------------------------------------------------------- |
| 样本不足                      | 未做或未完整做该检验；可看原始次数，勿过度解读。                                   |
| 未检出显著偏差（如 p ≥ 0.05） | 在当前样本下，与「52 张牌均匀出现」的整体差异**未达到**所选显著标准。              |
| 差异显著（如 p < 0.05）       | 在统计意义上与均匀假设**矛盾较明显**，宜**结合业务**再分析，避免直接定性为作弊等。 |

**不宜说**：「p 就是作弊概率」「χ² 越高就一定有问题」。**更准确的说法**：在「均匀」假设成立时，出现这么大或更大整体偏差的**罕见程度**由 p 反映。
